# 灵境易理 (I Ching App)

一款融合传统周易智慧与现代 AI 技术的数字化占卦工具。

## ✨ 核心特性

- **艺术化起卦体验**：支持**大衍筮法**（筹策）与**金钱卦**的动态视觉模拟，让数字化占卜不失仪式感。
- **AI 宗师级解卦**：集成 DeepSeek 等顶尖大语言模型，针对您的诉求提供深度、逻辑清晰且富有韵味的卦象解析。
- **现代美学设计**：基于 React 19 开发，拥有流畅的动画效果与精致的 HSL 配色方案，打造沉浸式的使用体验。
- **全栈安全部署**：已适配 Cloudflare Pages 全栈架构，通过边缘函数（Functions）隐藏 API 密钥，保障服务安全。

## 🛠️ 技术栈

- **框架**：React 19 + TypeScript
- **构建**：Vite
- **样式**：Vanilla CSS (Modern Design Tokens)
- **部署**：Cloudflare Pages + Functions (Node.js 运行时)
- **AI 引擎**：DeepSeek-V3 / SiliconFlow API
